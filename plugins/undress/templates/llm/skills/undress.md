---
name: Undress
action_hint: Character takes off the clothes it is wearing (undresses)
---
Take off everything you are wearing — you are undressed afterwards. Your clothing is a single described outfit, not a set of separate garments, so this removes all of it at once; the description is kept and GetDressed restores exactly it. No parameters needed. Use this when you undress in the scene (bathing, swimming, sleeping, changing, an intimate moment). Only call it when you really are taking your clothes off, not when you merely talk about it.
